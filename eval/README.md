Maintainer-only judge calibration. Not part of the installed package or any runtime path. Requires a live judge API key to run; skips cleanly without one. Run with `uv run python eval/calibrate.py` — if neither `AGENTPROBE_ANTHROPIC_API_KEY` nor `AGENTPROBE_OPENAI_API_KEY` is set, the script prints a skip message and exits 0 so CI without keys stays green. When a key is present, each triple in `calibration/cases.jsonl` is sent through the real judge, the verdict is compared to the hand-labelled `label`, and agreement is reported; exit is non-zero if agreement falls below the configured threshold (default 80 %).
